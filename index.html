04

How it works

  • Each build is one self contained HTML file. No server, no build step, no database, no accounts, no API keys.
  • Every map layer comes from a public body or from OpenStreetMap. No commercial imagery is used.
  • Nothing is stored in your browser. The page sets no cookies and uses no local storage.
  • Map tiles, elevation values and address searches are requested directly from the providers listed above.

Elevation readout. In Wallonia the figure is a real 50 cm terrain model value. In Luxembourg it comes from Copernicus GLO-90 at 90 m, because no keyless elevation service exposes the Luxembourg LiDAR. The readout labels which one it used.

Scan is beta. It compares surface and terrain hillshades to find structures with no cadastral footprint. It saturates under closed canopy and it is not a survey instrument.
